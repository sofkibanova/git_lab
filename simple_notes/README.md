Чтобы узнать IP у VM в терминале нужно выполнить: hostname -I

#

Перед запуском приложения нужно изменить имя пользователя и IP виртуальной машины в inventory.ini

Для запуска нужна команда:
ansible-playbook -i inventory.ini playbook.yml -u *USER_NAME* --ask-pass -ask-become-pass

#

Адрес приложения:
http://АЙПИ_ВИРТУАЛЬНОЙ_МАШИНЫ:8080
